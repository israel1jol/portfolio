# Modern Portfolio Website

A sleek, animated React portfolio website featuring smooth transitions, modern design, and responsive layouts. Built with React and Tailwind CSS for optimal performance and visual appeal.

## ✨ Features

### 🎨 Modern Design
- Clean, minimalist white background design
- Gradient text effects and animated backgrounds
- Professional color scheme with blue/purple gradients
- Responsive grid layouts that adapt to all screen sizes

### 🚀 Smooth Animations
- Staggered entrance animations for all elements
- Floating skill badges around profile photo
- Hover effects on buttons and project cards
- Rotating role/title text with smooth transitions
- Custom CSS animations (float, bounce, pulse)

### 📱 Multi-Page Navigation
- **Home Page**: Hero section with photo, projects showcase, and skills
- **About Page**: Comprehensive background, experience timeline, and stats
- Smooth page transitions without page reloads
- Active navigation state highlighting

### 🔗 Social Integration
- Social media links (GitHub, LinkedIn, Email) in top navigation
- Hover animations with scaling effects
- Always accessible across all pages

### 📊 Interactive Elements
- Featured projects with tech stack displays
- Achievement statistics with colorful gradient cards
- Experience timeline with professional formatting
- Skill badges with hover animations

## 🛠️ Built With

- **React** - Frontend framework with hooks (useState, useEffect)
- **Tailwind CSS** - Utility-first CSS framework
- **Lucide React** - Beautiful icon library
- **Modern JavaScript** - ES6+ features and best practices

## 🎨 Design Features

### Color Palette
- **Primary**: Blue (#2563EB) to Purple (#7C3AED) gradients
- **Secondary**: Green (#059669), Orange (#EA580C), Pink (#DB2777)
- **Neutral**: Gray scale from #F9FAFB to #111827
- **Background**: Clean white (#FFFFFF)

### Animation Types
- **Entrance**: Staggered slide-in animations with opacity transitions
- **Hover**: Scale transforms and color transitions
- **Floating**: Custom keyframe animations for skill badges
- **Rotation**: Smooth text cycling for role titles

### Responsive Breakpoints
- **Mobile**: < 768px - Stacked layouts, simplified navigation
- **Tablet**: 768px - 1024px - Adjusted grid columns
- **Desktop**: > 1024px - Full multi-column layouts
